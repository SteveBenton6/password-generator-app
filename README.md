# Password Generator App

## Uses HTML, CSS and JS

## Requirements

1. Build it from "scratch" (character array has been provided)
2. Generate two random passwords when the user clicks the button
3. Each password should be 15 characters long

## Stretch Goals

1.  Ability to set password length
2.  Add "copy-on-click"
3.  Toggle "symbols" and "numbers" on/off

## Specification (from Figma File)

1.  Main Text Typography: Karla, ExtraBold, 40px,
    color:night
2.  Second Line: #108981
3.  Small Text 20px, Inter, weight 400
4.  Bottom Box Fill: #ecfdf5
5.  Width: 1253px
6.  Height: 678px

## Concepts Used:

1. functions
2. The DOM
3. getElementById()
4. textContent
5. Array
6. Math.random
7. line-spacing
8. Flexbox
9. Horizontal Rule
